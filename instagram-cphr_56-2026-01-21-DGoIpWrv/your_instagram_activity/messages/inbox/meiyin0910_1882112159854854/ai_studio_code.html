常見問題

我的對話會被其他人看到嗎？ ▼

絕對不會。所有分析皆由程式自動完成，沒有任何人工介入。分析完成後，您的原始對話紀錄會被立即且永久地刪除。

需要伴侶同意嗎？ ▼

👫 雙方健檢：是的。上傳後系統會寄送確認信給雙方，兩人都點擊同意後，分析才會開始。這也是建立互信的第一步。

🪞 自我反思：不需要！自我反思是免費的問答流程，完全不需要上傳對話，也不需要對方參與。適合想先整理思緒的你。

如果報告不準怎麼辦？ ▼

AI 分析基於文字紀錄，可能無法完全捕捉語氣或面對面的互動。若您覺得報告對你們沒有幫助，請來信告知，我們將無條件退款。

怎麼下載 LINE / IG 對話？ ▼

LINE：在聊天室點選選單 → 其他設定 → 傳送聊天紀錄 → 以文字檔傳送。

Instagram：設定 → 帳號中心 → 下載你的資訊 → 選擇「訊息」並以 JSON 格式下載（約需 1-2 天）。

分析需要多久？報告怎麼收？ ▼

分析通常在 10 分鐘內完成。報告會以 Email 寄送給雙方（上傳時填寫的信箱），也可以在網站上直接查看。建議找個安靜的時間，兩個人一起閱讀。

如何下載對話紀錄

LINE 匯出步驟

  1. 打開與伴侶的聊天室
  2. 點擊右上角 ≡ 選單
  3. 選擇「其他設定」→「傳送聊天紀錄」
  4. 選擇「以文字檔傳送」
  5. 儲存 .txt 檔案

* 僅需文字檔，不包含圖片影片

Instagram 匯出步驟

  1. 打開 Instagram App → 設定
  2. 選擇「帳號中心」→「你的資訊和權限」
  3. 點擊「下載你的資訊」
  4. 選擇「部分資訊」→ 只勾選「訊息」
  5. 格式選擇 JSON
  6. 等待 Email 通知後下載

* 通常需要 1-2 天處理，請耐心等待

下載好後，回到這裡上傳即可開始分析 🎉

資料處理說明

① 資料傳輸

您上傳的對話檔案會透過 HTTPS 加密傳輸至我們的伺服器。傳輸過程中，任何第三方都無法讀取內容。

② AI 分析過程

您的對話會被送至 OpenAI 的 API 進行分析。根據 OpenAI 的 API 使用條款，透過 API 傳送的資料不會被用於訓練他們的模型。

③ 資料儲存

我們不會在伺服器上儲存您的原始對話內容。分析完成後，原始檔案會在 10 分鐘內自動刪除。我們只保留產出的報告（不含原文）。

④ 人工存取

整個分析過程完全自動化，沒有任何人工介入。我們的團隊無法也不會查看您的對話內容。

⑤ 您的權利

您可以隨時要求我們刪除您的報告資料。如有任何疑慮，歡迎來信 privacy@talkheal.tw 詢問。

簡單來說：您的對話只會被 AI 讀取一次，然後立即刪除。沒有人會看到，也不會被拿去做其他用途。
